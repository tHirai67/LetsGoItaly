# Italy Trip（イタリア旅行のしおり）

ローマ・フィレンツェ・ベネツィアを巡る旅行情報を、スマートフォンでも見られる静的サイトにまとめています。

## ページ構成

- `index.html`：各ページへのダッシュボード
- `schedule.html`：2027年2月6日〜14日の日別スライドと時刻順のタイムライン
- `spots.html`：都市別の観光地、訪問予定・歴史、OpenStreetMapの地図
- `reservations.html`：予約候補、料金目安、確認チェックリスト
- `todo.html`：初期TODO、追加可能なチェックリスト、共有ファイルの入出力
- `css/style.css`：全ページ共通のイタリア国旗色のデザイン、モバイル用ボトムナビ
- `js/main.js`：日程スライド、地図、絞り込み、ブラウザ内保存、TODO共有ファイル

## 公開方法（GitHub Pages）

1. リポジトリの **Settings → Pages** を開きます。
2. Sourceで **Deploy from a branch** を選び、公開するブランチと `/(root)` を指定します。
3. 公開URLを開いて、ページと地図が表示されることを確認します。

観光地マップはOpenStreetMapの地図タイルを使用するため、地図の表示にはインターネット接続が必要です。地図が読み込めない場合はOpenStreetMapへのリンクを表示します。

## 更新時の注意

- フライトの時刻は提供された情報を掲載しています。航空会社・便名は未共有のため記載していません。
- 都市間の列車時刻は予約前のため固定していません。購入後に `schedule.html` の移動情報を更新してください。
- 料金は大人1名あたりの概算です。営業時間・予約条件・価格・制度は変更されるため、予約前に公式情報を確認してください。
- 地図上の宿泊先はプライバシーに配慮し、共有された住所の正確な位置ではなくエリアの概略位置を表示します。
- 予約チェックとTODOは閲覧中のブラウザのローカルストレージに保存され、他の端末や閲覧者とは自動同期されません。
- TODOはJSONファイルで書き出してメンバーに送り、受け取った側がTODOページから読み込めます。読み込みは既存リストを置き換えるため、各自が変更後にファイルを再共有してください。リアルタイム共有には外部のデータベースサービスが必要です。
